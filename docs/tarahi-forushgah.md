# طراحیِ بصریِ فروشگاهِ ست‌شاپ — مبنا و تصمیم‌ها

> **مرجع جاری از ۲۰۲۶/۰۹/۲۲:** پوشه `قالب نمونه` و ترجمه آن به اجزای Next.js. پالت صورتی–بنفش، عرض ۱۳۲۰، پنل تیره/روشن و لایه `premium.css` جایگزین جهت‌گیری بصری قبلی شده‌اند. [تصمیم‌ها و نتایج واقعی آزمون](premium-redesign.md). بخش‌های زیر تاریخچه طراحی قبلی را توضیح می‌دهند.


این سند «چرا این شکلی است» را توضیح می‌دهد، نه «چه شکلی است».
شکل را در پیش‌نمایش ببینید؛ عددها و دلیل‌ها اینجا است.

## ۱) مبنا: استخراج از دو فایلِ الگو، نه حدس

دو فایلی که فرستادید (صفحاتِ ذخیره‌شده‌ی یک فروشگاهِ پیشروِ ایرانی)
با ابزار تحلیل شد و سیستمِ طراحیِ واقعیِ آن‌ها از دلِ CSS بیرون کشیده شد.
اعدادی که کیفیتِ ادراک‌شده را می‌سازند، همان‌هایی‌اند که اندازه‌گیری شدند:

| مقیاس | مقدارِ استخراج‌شده از فایلِ مرجع | what در ست‌شاپ اعمال شد |
|---|---|---|
| ریشه‌ی `rem` | `html { font-size: 10px }` | همان (هر `rem` = ۱۰ پیکسل) |
| عرضِ چیدمان | `max-width: 1676px` | همان (`--st-container`) |
| قلمِ بدنه | ۱۱–۱۲px، خطِ سیر ۲٫۱–۲٫۱۷ | ۱۳px با خطِ سیر ۱٫۸–۲٫۱ (کمی خواناتر) |
| قلمِ عنوان | ۱۴ / ۱۶ / ۱۸ / ۲۲px | همان، با وزنِ ۸۰۰ برای تیترِ اصلی |
| شعاع | ۴ / ۸ / ۱۲ / ۱۶px | همان (`--st-r-*`) |
| فاصله | ۴ / ۸ / ۱۲ / ۱۶ / ۲۰ / ۲۴ | همان (`--st-1` تا `--st-9`) |
| ارتفاعِ نوارِ بالا | دو ردیف (۶۴px + ۴۴px) | همان |
| خاکستریِ متن | `#3f4064` بدنه، `#81858b` کمکی | همان خانواده، کمی سردتر |
| رنگِ تخفیف | قرمز (`#ef4056`) | قرمزِ خودمان (`#e11d48`) |

**آیکونِ جستجو، منویِ آبشاری، چیدمانِ کارت، بلوکِ قیمت، نشانِ درصدِ تخفیف،
چیپ‌هایِ دسته‌بندی و نوارِ پایینِ موبایل** — همه از همان واژگانِ بصری پیروی
می‌کنند که در فایلِ مرجع بود، چون کاربرِ ایرانی این الگوها را از پیش می‌شناسد
و نیازی به یادگیری ندارد.

## ۲) تفاوتِ آگاهانه: هویتِ خودمان

| نقش | رنگِ مرجع | رنگِ ست‌شاپ | دلیل |
|---|---|---|---|
| برند (دکمه، پیوند، نشان) | قرمز | **نیلیِ تیره `#4a30d8`** | کپیِ هویتِ رقیب، ارزان دیده می‌شود؛ نیلی حسِ «فناوری/قطعه» می‌دهد |
| تخفیف | قرمز | قرمز `#e11d48` | در بازارِ ایران قرمز = تخفیف؛ این قرارداد را نمی‌شکنیم |
| امتیاز/پیشنهاد | — | کهربایی `#f59e0b` | تضاد با نیلی؛ فقط برای تأکید |
| موفقیت/خطا | `#3daa58` / `#eb3850` | `#0f9d58` / `#d92d20` | کنتراستِ بالاتر روی زمینه‌ی روشن |

اگر خواستید برند قرمز باشد، تنها یک خط تغییر می‌کند:
`apps/web/src/app/storefront.css` → `--st-brand`.

## ۳) برتری‌هایی که از مرجع فراتر رفته

1. **انتخابِ گوشی در نخستین نگاه** — قهرمانِ صفحه به‌جایِ بنرِ تبلیغاتی،
   انتخابگرِ گوشی است (برند → مدل، دو مرحله). در مرجع، کاربر باید جستجو کند؛
   اینجا مسیرِ اصلیِ خرید همان فیلترِ سازگاری است.
2. **جستجو با پیشنهادِ زنده** — با سه محافظت: دست‌کم ۲ نویسه، تأخیرِ ۲۸۰ms،
   و لغوِ درخواستِ قبلی (روی اینترنتِ موبایل، پاسخِ کندِ قبلی نباید پاسخِ تازه را خراب کند).
3. **افزودن به سبدِ سریع روی کارت** — بدون رفتن به صفحه‌ی کالا.
4. **موجودیِ واقعی روی هر کارت** — «۵۴ عدد در انبار» به‌جایِ «موجود».
5. **صاداقت در سبد** — اگر قیمت پس از افزودن تغییر کرده باشد، مبلغِ پیشین
   روی همان ردیف نوشته می‌شود.
6. **هیچ منبعِ خارجی** — قلم‌ها خودمیزبان (`public/fonts`، وزیرمتن)،
   آیکون‌ها SVGِ درون‌خطی (`components/store/icons.tsx`)، تصویرها در همین دامنه.
   سایت بدونِ اینترنتِ بین‌الملل کامل بالا می‌آید (الزامِ «فقط ایران»).

## ۴) ساختارِ فایل‌ها

```
apps/web/src/app/storefront.css        ← نشانه‌ها و اجزاء (۱۶ بخش، مستند)
apps/web/src/components/store/
   icons.tsx            ← ۲۰ آیکونِ درون‌خطی
   store-header.tsx     ← نوارِ دو ردیفه (نشان، جستجو، حساب، سبد، دسته‌بندی)
   search-suggest.tsx   ← جستجویِ زنده + میانبرِ Ctrl+K
   mega-menu.tsx        ← منویِ آبشاری: نوعِ کالا + مدل‌هایِ گوشی
   product-card.tsx     ← کارتِ کالا (تصویر، عنوانِ دوسطره، قیمت، موجودی، افزودنِ سریع)
   quick-add.tsx        ← کنشِ سروریِ افزودن به سبد
   device-picker.tsx    ← انتخابگرِ گوشی در قهرمانِ صفحه
   add-to-cart-box.tsx  ← جعبه‌ی خریدِ صفحه‌ی کالا (تنوع، تعداد، موجودی)
   search-filters.tsx   ← فیلترِ گوشی در نتایج (در نشانی می‌ماند)
   store-footer.tsx     ← پانوشتِ چهارستونه + نشان‌هایِ اعتماد
   tab-bar.tsx          ← نوارِ پایینِ موبایل
apps/web/src/app/page.tsx              ← صفحه‌ی نخست
apps/web/src/app/products/[slug]/      ← صفحه‌ی کالا
apps/web/src/app/search/               ← نتایجِ جستجو
apps/web/src/app/device/[id]/          ← کالاهایِ سازگار با یک گوشی
apps/web/src/app/cart/                 ← سبدِ خرید
```

## ۵) پاسخ‌گویی (Responsive)

| عرض | رفتار |
|---|---|
| ≥ ۱۴۴۰px | ۶ کارت در ردیف، ظرفِ ۱۶۷۶px |
| ۱۰۲۴–۱۴۳۹ | ۴ کارت |
| ۶۴۰–۱۰۲۳ | ۳ کارت؛ صفحه‌ی کالا تک‌ستونه |
| < ۶۴۰ | ۲ کارت؛ منویِ آبشاری و نوارِ دوم پنهان؛ **نوارِ پایین** (خانه، دسته‌بندی، سبد، حساب) ظاهر می‌شود |

# بازطراحی فروشگاه و پنل مدیریت — ۲۰۲۶/۰۹/۲۲

> **ادامه کار:** موانع نوع/شماره‌گذاری و آزمون تأمین که در گزارش تاریخی پایین آمده، رفع شدند؛ `verify` و ۸۷۵ آزمون محلی اکنون سبز هستند. [گزارش مرحله دوم](admin-stabilization.md).

## مبنا و محدوده

مرجع بصری: `قالب نمونه/setshop-premium.html`، با تأیید کارفرما برای فروشگاه **و پنل مدیریت**.
پیاده‌سازی همچنان TypeScript، React و Next.js است. هیچ HTML یا JavaScript اجرایی از نمونه جایگزین برنامه نشده و پوشه نمونه تغییر نکرده است.

- عرض فروشگاه ۱۳۲۰ پیکسل، زمینه روشن مایل به صورتی، سطوح سفید، بنفش و صورتی؛ صورتی اصلی کمی تیره‌تر از نمونه برای خوانایی متن سفید انتخاب شد.
- هیرو تیره با تصویر محلی، انتخاب واقعی مدل گوشی، گرید دسته‌های واقعی، کارت‌ها، نوار اعتماد، هدر و فوتر تازه.
- پوسته مشترک مدیریت: نوار کناری تیره ۲۵۰ پیکسلی، سربرگ مستقل، جستجوی منوی مجاز، شش گروه کاری، حالت فعال زیربخش‌ها و منوی بازشونده موبایل.
- پیشخوان: کارت‌های واقعی آمار، درآمد، نسبت وضعیت سفارش‌ها، میانبرهای متناسب با مجوز و جدول کم‌موجودی. هیچ نمودار، درآمد یا روند ساختگی وارد نشده است.
- جدول‌ها، فرم‌ها، تب‌ها، برچسب‌های وضعیت، فیلترها و دکمه‌های مشترک پنل از نظام بصری تازه استفاده می‌کنند. ساختار داخلی تک‌تک صفحات تجاری بازنویسی نشده است.
- زبان فارسی، RTL، فونت محلی Vazirmatn، مسیرها، نشست‌ها، کنترل دسترسی و کنش‌های سروری حفظ شدند.
- اصلاح همراه رابط: خطای دریافت کم‌موجودی دیگر با پیام «همه کالاها موجودی کافی دارند» اشتباه گرفته نمی‌شود؛ اطلاعات موجودی/تخفیف/رنگ API به کارت‌های صفحه اصلی منتقل می‌شود.

## محل نگهداری

- `globals.css`: توکن‌های عمومی و اجزای پایه.
- `storefront.css` و `account.css`: توکن‌ها و قواعد فروشگاه و حساب مشتری.
- `premium.css`: لایه چیدمان تازه، قواعد محدودشده به فروشگاه/پنل، واکنش‌گرایی، چاپ و کاهش حرکت.
- `admin-navigation.ts`: مسیرها، گروه‌ها، تطبیق مسیر و فیلتر مجوز/جستجو؛ هفت آزمون مستقل.
- `scripts/render-qalib.mjs`: چهار لایه CSS در خروجی خودکفا و هش ورودی‌ها لحاظ می‌شوند.
- `scripts/smoke-premium.mjs`: بررسی مرورگری قابل تکرار؛ تنظیمات و اطلاعات ورود فقط از محیط خوانده می‌شوند.

## سنجش انجام‌شده

- `npm run typecheck:web`: موفق.
- `npm run build:web`: موفق، بدون خاموش‌کردن بررسی TypeScript.
- `npx vitest run apps/web`: ۱۰ آزمون در ۲ پرونده موفق (۷ آزمون جدید ناوبری).
- `npm run template` و `npm run template:check`: موفق.
- `git diff --check`: موفق.
- Chromium واقعی: ورود مدیر، ۸ مسیر در عرض‌های ۳۶۰، ۷۶۸ و ۱۴۴۰ پیکسل؛ **۲۴ بررسی موفق** برای پاسخ ۲۰۰، نبود انتقال ناخواسته و نبود سرریز افقی سند. مسیرها: خانه، جستجو، سبد، حساب، پیشخوان، کالاها، سفارش‌ها، تنظیمات.
- باز و بسته شدن منوی موبایل، جستجوی منو و Escape موفق؛ در این اجرا خطای runtime مرورگر مشاهده نشد.
- صفحه جزئیات کالای نمونه نیز جداگانه با پاسخ ۲۰۰ بررسی شد. تصاویر صفحه اصلی و پیشخوان در دسکتاپ و موبایل بازبینی شدند.

اجرای دوباره آزمون مرورگر: وب و API آزمایشی را روشن کنید، متغیرهای `WEB_URL`، `BROWSER_EXECUTABLE_PATH`، `ADMIN_MOBILE` و `ADMIN_PASSWORD` را از محیط امن تنظیم کنید و `node scripts/smoke-premium.mjs` را اجرا کنید. حساب باید اجازه مشاهده مسیرهای آزمون را داشته باشد. این آزمون صرفاً نمایش/ناوبری را می‌سنجد، نه ثبت سفارش یا عملیات مالی.

## مانع‌ها و محدودیت‌های ثبت‌شده در پایان مرحله اول (تاریخی)

- `npm run verify`: در typecheck ریشه با **۳۷ خطا** متوقف شد. ۱۱ پرونده دارای خطا با HEAD مقایسه شدند و همگی پیش از این تغییر نیز همان محتوا را داشتند؛ مربوط به API، CRM و cart هستند، نه بازطراحی.
- `npm run typecheck:scripts`: دو خطای قبلی در `check-due-reminder.ts` و `reencode-media-webp.ts`.
- `npm run check`: دو خطا برای شماره تکراری ۰۳۹ مهاجرت‌ها و یک هشدار قدیمی کار ناتمام ایمیل. مهاجرت‌ها دست‌نخورده‌اند.
- `npm test`: اجرای کامل به نتیجه نهایی نرسید؛ پس از سقف زمانی و ادامه کارگر، برای بررسی مرورگری متوقف شد. پیش از توقف، **۵۳۱ آزمون در ۲۲ پرونده موفق** ثبت شد و پرونده procurement قرمز بود؛ این اعداد نتیجه کامل مجموعه نیستند.
- `npm audit`: **۱۶ آسیب‌پذیری** در وابستگی‌های موجود (۱۰ متوسط، ۵ شدید، ۱ بحرانی). هیچ بسته‌ای به پروژه اضافه یا ارتقا داده نشد؛ رفع وابستگی‌ها کار جداگانه می‌خواهد.
- همه صفحات مدیریت، همه نقش‌ها، ارسال فرم‌ها، پرداخت و عملیات مالی انتهابه‌انتها آزموده نشده‌اند. تأیید نهایی استقرار نیازمند رفع دروازه‌های قرمز و آزمون کامل است.

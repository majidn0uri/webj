۱) جریان اصلی — از خرید تا تحویل

فاز ۰ — راه‌اندازی اولیه مدیر

تعریف نقش‌ها و تیک دسترسی‌ها • پنل مدیریت کاربران • اطلاعات پایه (دسته‌بندی‌ها، بانک برند و مدل گوشی‌ها، تعرفه ارسال، روش‌های پرداخت) • شماره‌گذاری اسناد

فاز ۳ — خرید اقلام حسابدار

تعیین نیاز (هشدار نقطه سفارش) ← فاکتور خرید (KH) ← ثبت پرداخت: نقد / کارت / اعتباری (بدهی + سررسید) / چک

فاز ۴ — ورود و ثبت کالا انباردار / حسابدار

تطبیق با فاکتور خرید + ثبت مغایرت ← ثبت مشخصات: عکس‌ها، جدول مشخصات فنی، سازگاری با گوشی‌ها، قیمت خرید / فروش / همکاری، تخفیف (با تاریخ شروع و پایان)، رنگ‌ها با موجودی جداگانه ← برچسب‌گذاری ← تأیید ورود

فاز ۸ — بسته‌بندی و ارسال انباردار / اپراتور ارسال

پکینگ‌لیست و برچسب آدرس ← جمع‌آوری + کنترل نهایی (رنگ و تعداد) ← بسته‌بندی ایمن ← تحویل به شرکت حمل + ثبت کد رهگیری (MS) ← اطلاع کد رهگیری به مشتری ← پیگیری تا تحویل
▼
✓ تحویل به مشتری — پایان چرخه فروش
⚠ بعد از تحویل، «مرجوعی» و «لغو» ممکن است (بخش ۵) — و از لحظه ورود کالا به انبار، «فرآیندهای همزمان» (بخش ۲) همیشه فعال‌اند.
۲) فرآیندهای همزمان — همیشه در حال اجرا

انبار (انباردار)

  • موجودی در سطح رنگ — فروش منفی ممنوع
  • هشدار اتمام موجودی (نقطه سفارش)
  • ثبت ضایعات و معیوبی با دلیل
  • انبارگردانی دوره‌ای + تعدیل با دلیل

مالی، صندوق و چک (حسابدار)

  • ثبت روزانه: نقد، کارت‌خوان، کارت به کارت، درگاه
  • بستن صندوق پایان روز + تطبیق
  • چرخه چک‌های همکاران (بخش ۶)
  • تسویه فروشندگان • سود و زیان دوره‌ای

گزارش‌گیری و لاگ (مدیر / حسابدار)

  • فروش تفکیک: حضوری / آنلاین / همکار
  • سود هر کالا • موجودی و ارزش انبار
  • پرفروش‌ها (مبنای «ترند») و بی‌حرکت‌ها
  • لاگ فعالیت کاربران: چه کسی، چه چیزی، کِی
۳) سه نوع مشتری — قواعد اکانت، قیمت و پرداخت

مشتری حضوری

ساخت اکانتخودکار هنگام خرید، با کد ملی + شماره تماس
قیمت‌هاقیمت فروش (خرده‌فروشی)
پرداخت حضوریپول نقد یا کارت‌خوان
پرداخت آنلاینفقط درگاه آنلاین

مشتری آنلاین

ساخت اکانتثبت‌نام خودشان در سایت + تأیید پیامکی
قیمت‌هاقیمت فروش (خرده‌فروشی)
پرداخت حضوری—
پرداخت آنلاینفقط درگاه آنلاین

همکار (عمده‌خر)

ساخت اکانتثبت‌نام خودش یا ثبت توسط حسابدار + تیک «همکار» فقط توسط مدیر
قیمت‌هاقیمت همکاری — حضوری و آنلاین
پرداخت حضورینقد، کارت، پرداخت آنلاین یا چک
پرداخت آنلایندرگاه آنلاین یا چک
🔑 کلید یکتای مشتری: کد ملی — شناسه ورود: شماره موبایل — یک اکانت برای هر دو کانال (حضوری + آنلاین) — ساخت اکانت تکراری ممنوع
۴) مسیر مشتری در سایت
صفحه اولکالاهای تخفیف‌دار + ترندها ← دسته‌بندی / جستجو / فیلتربرند، قیمت، رنگ، سازگاری با گوشی، فقط موجودها ← صفحه کالاعکس‌ها + جدول فنی + سازگاری + رنگ و تعداد ← سبد خریدویرایش تعداد و حذف ← تکمیل خریدآدرس + ارسال و هزینه + پرداخت ← ثبت سفارش + پرداختکد سفارش + پیامک ← پنل مشتریسفارش‌های من + کد رهگیری + آدرس‌ها
👁 مرور سایت آزاد است (بدون ورود) اما ثبت سفارش فقط پس از ورود به اکانت — قیمت‌های نمایش‌داده‌شده بر اساس نوع اکانت: مهمان و عادی ← قیمت فروش | همکار ← قیمت همکاری
۵) وضعیت‌های سفارش آنلاین
ثبت‌شدهدر انتظار پرداخت ← پرداخت‌شدهدرگاه تأیید شد یا چک همکار ثبت شد ← تأییدشدهکنترل موجودی انجام شد ← در حال بسته‌بندی ← ارسال‌شدهکد رهگیری اعلام شد ← تحویل‌شده ✓پایان سفارش
لغوشده قبل از ارسال — برگشت وجه / ابطال چک + بازگشت موجودی مرجوع‌شده بعد از تحویل — بررسی ← انبار / ضایعات ← استرداد وجه یا اعتبار
۶) چرخه چک دریافتی — فقط همکاران
ثبت چکمبلغ، بانک، شماره، صیاد، سررسید، تصویر ← در جریانیادآوری قبل از سررسید ← سپرده به بانک ← وصول‌شده ✓بستن طلب
خرج‌شده واگذاری به فروشنده / طلبکار — تهاتر با بدهی برگشتی تماس با مشتری، چک / تعهد جدید، پیگیری قانونی
⚠ چک تا لحظه وصول «طلب از مشتری» است، نه پول نقد — گزارش سررسیدها و چک‌های باز باید همیشه در دسترس حسابدار باشد.
